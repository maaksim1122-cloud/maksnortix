Nortix Talk+

Месенджер із власним сервером в Україні для телефона й комп'ютера. Без номера телефону та SIM-карти: працює через сервер або без інтернету — по локальному Wi-Fi роутеру, Bluetooth і Wi-Fi Direct.

  • Наскрізне шифрування повідомлень, файлів і дзвінків (Double Ratchet, P-256 ECDH, AES-256-GCM)
  • Медіа та файли до 5 ГБ: потокове шифрування й передача блоками по 1 МБ без навантаження на пам'ять — через сервер і локально через Wi-Fi
  • Секретні чати: ізольовані ключі на конкретні два пристрої, без синхронізації й бекапів, захист від скриншотів, візуальний ключ 8×8 і таймер самознищення
  • Офлайн через Wi-Fi роутер: повноцінне листування, передача файлів до 5 ГБ та аудіо/відеодзвінки навіть без підключеного кабелю провайдера
  • Клієнти для Windows 7/8/10/11 і Linux (.deb, .pkg.tar.zst) з підписом офіційним GPG-ключем

Відомості про компанію

MaksNortix company — незалежна технологічна компанія. Ми робимо програми, якими користуємось самі, і не збираємо даних більше, ніж потрібно для роботи.

Приватність за замовчуванням

Продукти не вимагають номера телефону чи пошти. Налаштування видимості, як-от час останньої активності, діють в обидва боки.

Чесність щодо обмежень

Ми пояснюємо, що наші програми роблять, а чого ні. Наприклад, у Nortix Talk сервер дзвінків бачить IP-адресу, поки не ввімкнено режим ретранслятора. Незалежного аудиту безпеки поки не було.

Відкритий код

Код Nortix Talk опубліковано, тож його можна перевірити й зібрати самостійно.

Про компанію

Чим займається MaksNortix company?

Створюємо застосунки для приватного зв'язку без реклами й стеження: месенджери Nortix Talk і Nortix Talk+ для Android, Windows і Linux.

Як зв'язатися з командою?

Напишіть нам у месенджері або створіть запит у репозиторії проєкту на GitHub.

Nortix Talk і Nortix Talk+

Чи потрібен номер телефону або SIM-карта?

Ні. Криптографічні ключі генеруються локально на пристрої. У класичному Nortix Talk немає ані номера, ані пошти; у Nortix Talk+ пошта використовується лише для коду входу при перенесенні чи підключенні ПК.

Як працює месенджер без інтернету (через Wi-Fi роутер чи Mesh)?

Коли інтернет вимкнений або від'єднаний кабель провайдера, але Wi-Fi роутер підключений до живлення — пристрої в одній мережі Wi-Fi автоматично знаходять одне одного безпосередньо (UDP/TCP LAN Mesh), а смартфони поруч додатково з'єднуються через Bluetooth / Wi-Fi Direct. Працюють чати, секретні чати, передача файлів до 5 ГБ та аудіо/відеодзвінки!

Який максимальний розмір фото, відео та файлів?

До 5 ГБ на одне фото, відео чи документ. Файли понад 4 МБ шифруються й передаються потоковими блоками по 1 МБ (AES-256-GCM на кожен блок) без навантаження на пам'ять, з підтримкою докачування та відсотками прогресу як через сервер (до 7 днів для файлів > 100 МБ), так і напряму по Wi-Fi LAN.

Як працюють Секретні чати?

Виберіть + → 🔒 Новий секретний чат або відкрийте меню ⋮ → 🔒 Почати секретний чат у звичайному діалозі. Секретний чат прив'язується тільки до двох конкретних фізичних пристроїв (окремий P-256 Double Ratchet), не синхронізується на інші пристрої, не потрапляє в резервні копії й Google Диск, забороняє пересилання та скриншоти (FLAG_SECURE / захист вікна), сповіщає про спробу знімка екрана, має візуальний ключ 8×8 і таймер самознищення після прочитання.

Чи видає дзвінок мою IP-адресу?

Дзвінки працюють напряму (peer-to-peer WebRTC). У стандартному режимі «Тільки в локальній мережі» запити до STUN/TURN не виконуються й контакту передається лише локальна LAN-адреса (напр. 192.168.x.x), тож дзвінки працюють навіть без інтернету через роутер. Повідомлення й файли ніколи не показують ваш IP співрозмовнику.

Що означає «Переглянути один раз» (🔥)?

Текст або фото, яке одержувач може відкрити лише один раз у захищеному від скриншотів вікні; після закриття вміст миттєво знищується на обох сторонах.

Як перевірити ключ шифрування чату?

У звичайному чаті відкрийте ⋮ → 🔑 ID (код безпеки), а в Секретному чаті — ⋮ → 🔑 Ключ шифрування, щоб звірити кольоровий візерунок 8×8 і відбиток особисто чи під час дзвінка.

Чи можна користуватися одним акаунтом на телефоні та ПК і як працюють бекапи?

У Nortix Talk+ комп'ютери (Windows і Linux) підключаються як окремо сертифіковані пристрої зі своїми ключами, а резервна копія шифрується вашим паролем (PBKDF2 + AES-256-GCM). Секретні чати та їхні ключі ніколи не синхронізуються й не експортуються в бекапи.

Для яких систем доступні застосунки?

Nortix Talk+ доступний для Android (F-Droid і APK), Windows 10 / 11 (64-bit), Windows 7 / 8 / 8.1 (32 та 64-bit), Kali / Debian / Ubuntu / Linux Mint (.deb) та Arch Linux / Manjaro (.pkg.tar.zst). Усі пакети підписані GPG-ключем.
